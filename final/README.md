# 期末專案報告

- 日期：2027/01/07（第 18 週，期末考週 1/4–1/10）
- 形式：3–4 人一組，上台報告＋Demo；繳交 WORD 報告、PPT 投影片，並附專案 GitHub repo 連結
- 內容：做一個有資料庫的網站（如訂票、報名、盤點、留言板等）

## 報告章節

| 章節 | 內容 |
|------|------|
| 系統簡介與動機 | 做什麼、為誰做、解決什麼問題 |
| 資料庫設計 | ER 圖、資料表結構、正規化說明 |
| 系統功能 | 主要功能與畫面 |
| 實作說明 | 用到的技術（PHP、MySQL、PDO、AJAX 等） |
| **測試與驗證** | 功能驗收表、SQL 注入試探結果、壓力測試數字（Requests/sec）、索引前後 EXPLAIN、發現與修正的問題 |
| 分工與心得 | 每人負責的部分、遇到的困難與解法 |

- **測試與驗證章**是本課程重點：要展示你們如何確認系統功能正確、擋得住惡意輸入、撐得住壓力，以及如何驗證 AI 產出的程式。
- 專案 repo 請設為 public 或把老師 `pychang-ai` 加為 collaborator。
