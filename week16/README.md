## 作業W16 學習單（1 題）

**題目**：從你的專案挑一個功能（例如登入、查詢、新增），做一次完整驗證：寫驗收表（輸入→預期）、跑功能測試、試一個邊界值、試一次錯誤路徑，記錄結果與發現的問題。

**資料**：自己的專案。

**繳交物**：驗收表＋測試截圖＋一句「發現的問題／本次未發現」。

**評分要點（Pass／Fail）**：驗收表齊全；至少測了功能＋邊界或錯誤路徑；有記錄發現。
