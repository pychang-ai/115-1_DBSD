## 作業W02 學習單（1 題）

**題目**：在 `C:\xampp\htdocs\ch02\` 底下建立 `hello.php`：第一行用 `echo` 印出你的姓名與學號，接著呼叫 `phpinfo()`。用 VS Code 的【Open PHP/HTML/JS in browser】執行，或在瀏覽器開 `http://localhost/ch02/hello.php`（**課本 1-4-3 把 Apache 改成 8080 埠，若你照做了就要開 `http://localhost:8080/ch02/hello.php`**）。

**資料**：自己的學號與姓名。

**繳交物**：瀏覽器畫面截圖：看得到你的姓名學號那一行與 phpinfo 表格。

**評分要點（Pass／Fail）**：phpinfo 有出現；有印出自己的姓名學號（不是範例值）。
